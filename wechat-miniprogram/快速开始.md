# 快速开始指南 ⚡

## 🎯 5分钟启动项目

### 第1步：安装开发工具（2分钟）
1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 安装并启动
3. 使用微信扫码登录

### 第2步：导入项目（1分钟）
1. 点击"导入项目"
2. 选择 `wechat-miniprogram` 文件夹
3. 填入测试AppID（或使用测试号）
   - 测试AppID：`wxYOUR_TEST_APPID`
   - 或勾选"不使用AppID"进行开发

### 第3步：配置后端（1分钟）
编辑 `app.js` 第7行：
```javascript
backendUrl: 'https://your-backend-url.com', // 改为你的后端地址
```

### 第4步：运行项目（1分钟）
1. 点击"编译"按钮
2. 在模拟器中查看效果
3. 点击"预览"扫码在真机测试

## 🔧 开发模式配置

在开发阶段，建议进行以下配置：

### 1. 关闭域名校验
点击右上角"详情" → 勾选：
- ☑️ 不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书

### 2. 打开调试模式
点击右上角"调试器"：
- 查看Console日志
- 查看Network请求
- 查看Storage数据

### 3. 清除缓存
点击右上角"清缓存" → 选择：
- 清除文件缓存
- 清除数据缓存
- 清除授权数据

## 🐛 遇到问题？

### Canvas不显示
**原因**：canvas-id可能冲突
**解决**：检查页面中的canvas-id是否唯一

### 图片上传失败
**原因**：后端地址未配置或域名不合法
**解决**：
1. 检查 `app.js` 中的 backendUrl
2. 开发时勾选"不校验合法域名"

### 页面无法跳转
**原因**：页面路径未在 app.json 注册
**解决**：在 app.json 的 pages 数组中添加页面路径

### 获取用户信息失败
**原因**：wx.getUserProfile 需要用户授权
**解决**：必须在button组件的点击事件中调用
